# 房东记账

一个装在自己手机上的记账本，用来管出租房：哪间房租出去了、租给谁、租金多少、这个月收到没有。

**不联网也能用。数据只存在你自己手机里，不会上传到任何地方。**

---

## 怎么把它装到手机上

### 第 1 步：打开网址

手机用 **Chrome** 或 **Edge** 浏览器打开：

```
https://xiaohao-ly.github.io/my-ledger/
```

> ⚠️ **不要用微信打开**。微信内置的浏览器不支持"添加到主屏幕"，
> 你会怎么都找不到安装按钮。

### 第 2 步：装到桌面上

页面顶栏如果出现一个白色的 **「装到桌面」** 按钮，直接点它，再确认一下就行。

**没看到那个按钮？** 用浏览器菜单装：

1. 点右上角的 **⋮** 菜单
2. 选 **「安装应用」** 或 **「添加到主屏幕」**
3. 桌面出现「房东记账」图标，点开就是 App

装成功后：
- 桌面上有独立图标（不是 Chrome 的图标）
- 点开**看不到网址栏**，看起来就像正常的 App

### ⚠️ 不要用「无痕模式」

无痕模式下存的数据，关掉窗口就没了。**一定要用正常模式打开。**

## 数据安全（重要）

### 你的数据存在哪

**只存在你这台手机的浏览器里。** 不上传、不同步、任何人都看不到。

好处是绝对私密。代价是：**手机丢了、清了浏览器数据，数据就没了。**

### 什么情况会丢

| 会丢 | 不会丢 |
|---|---|
| 手机丢了 / 坏了 | 关掉 App |
| 清理浏览器数据 / 存储空间 | 手机重启 |
| 卸载浏览器 | 断网 |
| 点「清除浏览数据」 | App 更新版本 |
| 用无痕模式打开 | 换 Wi-Fi |

### 请每月备份一次

```
打开 App → 右上角齿轮 ⚙（设置）→ 导出备份
→ 得到一个文件 → 发到微信文件传输助手或自己的邮箱保存
```

### 换手机怎么搬

```
旧手机：导出备份 → 通过微信/邮箱发给自己
新手机：打开网址 → 装成 App → 导入备份
```

**顺序很重要**：一定**先在旧手机上导出**，再在新手机上导入。
旧手机的数据在你确认新手机没问题之前，**不要删**。

---

## 两种导出，别搞混

| | **导出 Excel 表格** | **导出备份** |
|---|---|---|
| 给谁用 | 给人看 | 给 App 用 |
| 长什么样 | 真 Excel 文件，打开就是表格 | 一个数据文件，打开是乱码（正常） |
| 干什么用 | 查看、打印、存档、发给别人 | 换手机、误删后恢复 |
| 能用来恢复吗 | ❌ 不能 | ✅ 能 |

**换手机时两个都要导。**

---

## 打不开怎么办

**GitHub 在国内访问有时不稳定。** 如果网页打不开：

1. 试试切换 Wi-Fi / 移动数据
2. 多试几次，或者换个时间段
3. 还是不行的话，换用 **Cloudflare Pages**（同样免费、同一批文件、
   同样能装成 App），数据不用重新录

## 给开发者

这个 App 的设计文档在 [CLAUDE.md](CLAUDE.md)，
里面有完整的需求、技术方案、数据模型和开发步骤。

技术栈：纯 HTML/CSS/JavaScript，**零依赖、零构建步骤**。

### 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 界面 + 数据库层（所有页面代码都在这） |
| `calc.js` | 算账的大脑：日期、金额、租期、收租状态。**纯计算，可测试** |
| `sw.js` | 离线小工。**必须独立文件**，且绝不碰数据库 |
| `manifest.webmanifest` | 告诉手机"我是个 App" |
| `icons/` | 图标（由 `tools/make-icons.mjs` 用代码画出） |
| `tools/` | 开发辅助工具，**不上传到网上给 App 用** |
| `tests/` | 自动测试 |

### 改动后、推送前，跑一遍全检

```
node tools/check.mjs
```

它会跑：算账逻辑测试（82 项）、数据库集成测试（36 项）、
文件完整性、关键写法检查。**全绿才推送。**

单独跑某一项：

```
node tests/calc.test.mjs     # 只跑算账逻辑
node tests/db.test.mjs       # 只跑数据库（需要先 npm install fake-indexeddb）
node tools/make-icons.mjs    # 重新生成图标
```

> `fake-indexeddb` 只是电脑上的测试工具，**不会进 App**。
> App 本身必须保持零依赖、零网络请求。
